## Data Collection Steps

Use the aws___call_aws tool to collect the following information in this exact order:

### Step 1 — Change Set Analysis
1. Call cloudformation:ListChangeSets on stack "${STACK_NAME}".
   Find the most recently executed change set (ExecutionStatus = "EXECUTE_COMPLETE" and most recent CreationTime).

2. Call cloudformation:DescribeChangeSet with that change set name and StackName "${STACK_NAME}".
   Capture the full Changes list including property-level Details for each resource change.

### Step 2 — Stack State
3. Call cloudformation:DescribeStacks on "${STACK_NAME}".
   Capture: Outputs, Parameters, StackStatus, CreationTime, LastUpdatedTime, Description.

4. Call cloudformation:DescribeStackEvents on "${STACK_NAME}".
   From the returned events, find those with Timestamp >= "${BUILD_START_TIME}".
   If such events exist, use them as the current deployment's timeline (from the first UPDATE_IN_PROGRESS / CREATE_IN_PROGRESS through the matching UPDATE_COMPLETE / CREATE_COMPLETE or ROLLBACK).
   If NO events exist after "${BUILD_START_TIME}", the stack was NOT changed in this pipeline run — record ステータス as "⏭️ 変更なし" and set both duration fields to "N/A (スタック変更なし)".

### Step 3 — Resource Inventory
5. Call cloudformation:ListStackResources on "${STACK_NAME}".
   Capture all current logical resources with their physical IDs and resource types.
